hermetic is a desktop app with the `hermetic` CLI bundled inside it. It runs on macOS and Linux. The prebuilt, signed app is for Macs with Apple silicon; on Linux or an Intel Mac you run it from source. {/* design.md §3.6; README.md "Install" */}

## Requirements

- A Mac with Apple silicon for the prebuilt app, or Linux or an Intel Mac to run from source. On Windows, use WSL2 and follow the Linux steps (untested). {/* design.md §3.6 (macos-arm64 artifacts only); README.md "Install" */}
- For a real fleet: an AWS account and a Tailscale tailnet. [Your first fleet](/docs/start/first-fleet/) lists exactly what each needs. {/* README.md "Prerequisites" */}

## Linux and Intel Macs

There is no package for these yet, but the app and the CLI run on Linux and Intel Macs from a checkout of the repository. The README's [Linux and Intel Macs section](https://github.com/esopian/hermetic#linux-and-intel-macs) has the commands. The rest of this page is about the Mac app. {/* README.md "Install" › "Linux and Intel Macs" */}

## Install the app

1. Download `macos-arm64-Hermetic.dmg` from the [latest release](https://github.com/esopian/hermetic/releases/latest).
2. Open it and drag `Hermetic.app` into `/Applications`.

The app is signed with a Developer ID and notarised by Apple, so it opens like any other Mac app. v0.3.0 and earlier were not: if one of those reports that it is damaged, clear the quarantine flag once with `xattr -dr com.apple.quarantine /Applications/Hermetic.app`. {/* design.md §3.6; README.md "Install" */}

## Install the CLI

In the app's menu, choose **Install Command Line Tool…**. It writes a shim at `/usr/local/bin/hermetic` that points at the binary inside the app, so the CLI stays at the same version as the app. {/* design.md §3.6; README.md "Install" */}

Check it:

```sh
hermetic --version
```

## Updates

The app checks for a new release on launch and every six hours. It downloads a patch when you are one release behind and the full archive otherwise, and applies it on the next restart. {/* README.md "Install"; design.md §3.6 */}

The update check is unauthenticated, so it only works once the `esopian/hermetic` repository is public. While it is private, update by downloading the newer DMG. {/* design.md §3.6 */}
