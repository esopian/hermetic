hermetic manages a fleet of Hermes agents on AWS from a macOS desktop app and a CLI that share one core. {/* README.md intro; design.md §1 "If it isn't in core, it doesn't exist" */}

Each agent is an EC2 instance with no inbound network rules. You reach it over Tailscale and nothing else. {/* design.md §1 "Sealed inbound, open outbound", §7.2 */} The instance can be replaced at any time; the EBS data volume where the agent keeps what it has learned outlives it. {/* design.md §1 "Instances are disposable, volumes are precious" */}

hermetic is pre-alpha. {/* README.md "Status" */}
